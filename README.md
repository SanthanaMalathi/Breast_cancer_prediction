Breast Cancer Prediction Using Neural Network

This project leverages a Deep Neural Network (DNN) to classify breast tumors as Malignant or Benign using the Breast Cancer Wisconsin Dataset. The workflow includes data preprocessing, feature scaling, neural network model development using TensorFlow/Keras, and performance evaluation through accuracy, confusion matrix, precision, recall, and F1-score.

🚀 Technologies Used
Python
Pandas & NumPy
Scikit-Learn
TensorFlow / Keras
Matplotlib & Seaborn
📌 Key Features
Data preprocessing and normalization
Deep learning-based binary classification
Model evaluation using multiple metrics
Breast cancer prediction on new patient data
🎯 Outcome

The model effectively learns patterns from diagnostic breast cancer data and provides accurate predictions, demonstrating the potential of deep learning in healthcare and disease diagnosis.
